# Changelog

## 1.0.0 — 2026-09-27

Initial working release of Aurex.

- C++17 price-time exchange with funded accounts, reservations, explicit fees, and event-level invariants.
- Seeded event-driven simulation with baseline market makers, background traders, execution slices, latency, and shocks.
- React market, trader, and experiment views with dark and light themes.
- Live updates, saved scenarios, replay, command journals, paired experiments, and JSON exports.
- macOS launcher, documented headless execution, examples, and macOS/Linux CI.
- Seven C++ test groups and six Python integration tests.
